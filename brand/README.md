# Groupcade brand

The TV mascot and his three phone friends (coral, yellow, mint). Wordmark: "groupcade" in Baloo 2 ExtraBold, drawn as shapes.

- `groupcade-logo*.svg`: stacked logo (light, dark, sticker outline for color backgrounds)
- `groupcade-horizontal*.svg`: TV + wordmark for headers
- `groupcade-wordmark*.svg`, `groupcade-mascots.svg`, `groupcade-tv.svg`
- `app-icon-1024.svg` (square; stores round the corners), `android-foreground-1024.svg`, `favicon.svg`
- `og-image-1200x630.svg`: link preview
- `png/`: rendered PNGs (app icon has no alpha, as the App Store requires)

Colors: indigo #4A3AFF, navy ink #1B1F3B, sky #CFEBFF, blue #5BB8F5, coral #FF6B4A, sunshine #FFC93C, mint #3DD68C. Body font Nunito.
The plugin serves its copies from `plugin/groupcade/assets/brand/`; the app uses `app/assets/`.
